## 💻 Featured Projects

### 🔗 SureD — Blockchain Rental Deposit Platform

> **Secure rental deposits through blockchain-powered escrow.**

SureD is a full-stack platform designed to make rental deposits more transparent and secure for **students and landlords**.

The system uses **Stellar Soroban smart contracts** to manage deposits through an escrow-based workflow, reducing dependency on trust between parties.

**Highlights**

* 🔐 Smart-contract-powered rental deposit escrow
* 👨‍🎓 Dedicated student workflow
* 🏠 Landlord dashboard and confirmation flow
* 🔗 Stellar blockchain integration
* 💳 Wallet-based interactions
* 🧩 Full-stack architecture

**Stack:** `React` · `TypeScript` · `Tailwind CSS` · `Node.js` · `Express` · `MongoDB` · `Rust` · `Stellar Soroban`
