### 🔗 SureD

**Blockchain-powered rental deposit escrow platform**

SureD is a full-stack platform designed to make rental deposits more secure and transparent for students and landlords.

The project uses **Stellar Soroban smart contracts** to manage deposits through an escrow-based workflow, reducing dependency on trust between parties.

**Highlights**

* 🔐 Smart-contract-powered escrow
* 👨‍🎓 Student-focused rental workflow
* 🏠 Landlord confirmation workflow
* 🔗 Stellar blockchain integration
* 💳 Wallet-based interactions
* 🧩 Full-stack architecture
* 🛡️ Transparent deposit handling

**Tech:** `React` `TypeScript` `Tailwind CSS` `Node.js` `Express` `MongoDB` `Rust` `Stellar Soroban`
