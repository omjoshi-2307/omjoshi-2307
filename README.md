## 👋 About Me

I'm **Om Joshi**, a first-year **B.E. Information Technology student at NMIET, Pune**, interested in building practical software and gradually specializing in **cybersecurity and secure software engineering**.

I learn best by building things rather than only studying them — from web applications and robotics projects to hackathons, computer vision prototypes, and blockchain-based applications.

Right now, I'm focused on strengthening the fundamentals that sit underneath good security:

**Programming → DSA → Operating Systems → Networking → Web Development → Application Security**

> **My approach:** Learn the fundamentals. Build something with them. Break it. Understand why. Improve it. 🔁

## ⚡ What I'm Working On

### 🏠 SureD 2.0

A blockchain-powered rental security deposit platform being expanded from a **single tenant-landlord escrow workflow to multi-tenant rental agreements**.

Current exploration includes:

* Multi-tenant contribution tracking
* Split security deposits
* Co-tenant participation
* Shared escrow workflows
* Multi-party confirmation
* Better tenant/landlord UX

**Stack:** `React` `TypeScript` `Tailwind CSS` `Node.js` `Express` `MongoDB` `Stellar` `Soroban`

---

### 🛰️ DepthWizard — SIH 2026

**Smart India Hackathon 2026 • ISRO / Department of Space • PS26175**

Leading **Team SochX Horizon** on a prototype exploring:

```text
RGB Remote-Sensing Image
        ↓
AI Depth Estimation
        ↓
Depth / Elevation Representation
        ↓
DSM Generation
        ↓
3D Terrain Flythrough
```

The project explores how monocular optical imagery can be used to generate useful terrain/elevation representations for **disaster-management workflows**.

**Stack:** `Python` `Computer Vision` `Monocular Depth Estimation` `Geospatial Data` `3D Visualization`

## 01 — SureD

**Blockchain Rental Security Deposit Escrow**

> Making rental security deposits more transparent through verifiable escrow workflows.

```text
Tenant
  ↓
Deposit Funding
  ↓
Smart Escrow
  ↓
Tenant + Landlord Confirmation
  ↓
Release / Refund
```

**Highlights**

* Blockchain-backed escrow workflow
* Tenant-landlord confirmation flow
* Transparent deposit release process
* Multi-tenant expansion planned in SureD 2.0
* Collaborative development with Khushal Choudhary

**My contribution:** application development, frontend interfaces, state management and full-stack integration. Khushal led the Soroban smart-contract engineering.

**Built with:** `React` `TypeScript` `Tailwind` `Node.js` `Express` `MongoDB` `Stellar` `Soroban`

🔗 [Repository](https://github.com/Khushal-93/SureD) • [Live Application](https://sure-d.vercel.app/)
