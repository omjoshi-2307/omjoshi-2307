**Single-view height estimation and 3D flythrough**

<img src="./assets/projects/depthwizard.svg" alt="DepthWizard computer vision pipeline" width="100%" />

A team project concept for **Smart India Hackathon 2026, SIH26175 / PS26175**. Proposed pipeline: RGB image → AI depth → depth map → digital surface model → 3D view.

Non-georeferenced images produce relative estimates; georeferenced inputs can support metric DSM outputs.
